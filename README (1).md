# BudgetGenie - Personal Expense & Budget Planner

BudgetGenie is a sleek, single-page web app for tracking income, categorizing daily expenses, monitoring monthly category budget limits, and visualizing data analytics with native SVG charts. Includes user authentication screens and local storage data persistence.

## Key Features
- **User Authentication Screen:** Login & Create Account views with seamless guest preview support.
- **Financial Analytics Dashboard:** Total Income, Expenses, Net Balance counters, and SVG donut spending chart.
- **Category Budget Indicators:** Dynamic color-coded progress bars showing category limits vs spent amounts.
- **Transaction History & Controls:** Add/delete entries, multi-type filtering, sample data generator, and CSV exporter.

## Quick Start
1. Download `index.html`.
2. Open `index.html` directly in any web browser to test locally or host on GitHub Pages!
